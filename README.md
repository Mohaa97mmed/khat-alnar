# خط النار

لعبة استراتيجية شخصية — تحرير العراق من «جبهة العقرب».

- `khat-alnar.html` — اللعبة كاملة (ملف واحد يعمل دون إنترنت).
- `version.json` — رقم النسخة الحالية وملاحظات التحديث؛ يقرؤه البرنامج على الماك للتحديث التلقائي.
